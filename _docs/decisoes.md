# Decisões do site da Pode Curtir

Registro das decisões da Jéssica que mudaram este site. Este repositório é público: o que é interno (situação de
autorizações, riscos, valores de cliente) fica no Trello, não aqui. A mais recente fica no topo. Cada linha diz o que foi
decidido, quando e em qual PR entrou. Os testes em `_tests/` conferem as regras marcadas com ✔ para que elas não
voltem atrás sem querer.

## Regras que valem para qualquer mudança

- Não publicar o telefone ou o WhatsApp de cliente. ✔
- Pessoa identificada na página (nome ou rosto) só com autorização por escrito.
- Termos e contratos seguem o modelo padrão aprovado em 12/11/2026 (o mesmo layout do termo da Lucia Vidotto), em
  PDF e Word, com o nome do arquivo no padrão Empresa_Contato.
